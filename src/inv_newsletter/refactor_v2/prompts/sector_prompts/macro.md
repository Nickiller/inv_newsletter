# Sector Prompt — 宏观与市场

## 板块特色

宏观与市场板块覆盖：货币政策、宏观经济数据、地缘政治与能源、商品市场、利率与汇率、市场情绪与持仓、跨资产联动。

## 主题归类提示

常见主题（仅供 reference，实际主题以 Stage A triage 输出为准）：

- Fed / ECB / BOJ 政策动态
- CPI / PCE / NFP / GDP 数据点评
- 地缘政治（中东、俄乌、台海等）→ 油价 / 商品 / 避险
- 国债收益率 / 信用利差
- 仓位与情绪：CFTC / 期权 skew / Mag7 sentiment / 资金流向

## 板块特有写作提示

- 宏观信息无法归到单一 Ticker 时，用子主题分类（如"地缘政治与能源"、"市场情绪"），不要硬凑 Ticker 段落
- 多源覆盖更常见：同一宏观事件常被 3+ 卖方提及 → 适合表格化
