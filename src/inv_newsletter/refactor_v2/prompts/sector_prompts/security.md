# Sector Prompt — 网络安全

## 板块特色

网络安全板块覆盖：endpoint（CRWD / S）、network security（PANW / FTNT / NET）、identity（OKTA）、SIEM / observability（DDOG / SPLK）、cloud security（ZS）、newer cybersecurity 上市公司。

## 主题归类提示

常见主题（仅供 reference，实际主题以 Stage A triage 输出为准）：

- AI 对 cyber 工作流的影响（autonomous SOC、AI red-teaming）
- 平台整合 vs point solution 竞争
- 重大 breach 事件 → 行业 read-through
- 政府/合规驱动需求（CISA 政策、CMMC 等）
