# Sector Prompt — 半导体与硬件

## 板块特色

半导体与硬件板块覆盖：存储、Foundry、先进封装、设备、CPU/GPU、网络与光通信、PCB/被动元件、服务器与终端硬件、汽车/工业半导体。

## 主题归类提示

常见主题（仅供 reference，实际主题以 Stage A triage 输出为准）：

- 存储超级周期 + LTA 重估（MU / SK Hynix / Samsung / WDC / STX / SNDK / 兆易创新）
- 先进封装与 Foundry 三方竞争（TSMC / Samsung Foundry / Intel Foundry / MediaTek / ASE / Amkor）
- 光通信供需缺口（COHR / LITE / FN / CRDO / ALAB / MRVL / AVGO）
- CPU TAM Re-rate（INTC / AMD / ARM）
- AI 服务器 / hyperscaler capex（NVDA / AVGO / DELL / SMCI / ANET）
- 设备链（ASML / AMAT / LRCX / KLAC / BESI / SOITEC）

## 板块特有写作提示

- 半导体板块**主题驱动性最强**——超级周期 / Foundry 之争 / 光通信缺口等大叙事跨多个 Ticker，**优先按主题组织而非按 Ticker 平铺**
- mega-cap 半导体（NVDA, AMD, AVGO, TSMC, INTC）即使单源覆盖也倾向独立成段
- 久谦专家纪要在本板块特别有价值（产业链拆解、单位经济、产能、份额）→ 单独成段叙述
- 设备链 Ticker（ASML / AMAT 等）信号常作为 Foundry / Memory 主题的派生 → 归入相关主题内，不另起设备段
