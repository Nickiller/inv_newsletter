# Sector Prompt — 软件与SaaS

## 板块特色

软件与 SaaS 板块覆盖：基础软件（MSFT / ORCL / NOW / CRM）、应用 SaaS（HUBS / BILL / TEAM / TWLO）、数据库与基础架构（SNOW / DDOG / NET / MDB）、垂直 SaaS（VEEV / CDLX 等）、开发者工具（GTLB / FROG 等）。

## 主题归类提示

常见主题（仅供 reference，实际主题以 Stage A triage 输出为准）：

- AI 对 SaaS 商业模式的冲击（seat-based 定价 vs outcome-based）
- Cloud 工作负载迁移与多云竞争
- 企业 IT 支出趋势（IT budget surveys、CIO surveys）
- M&A 与私有化（PE 收购、整合）
- 季度财报：NRR、cRPO、billings、margin

## 板块特有写作提示

- 软件板块**财报驱动性强**——季度数据 (NRR / cRPO / RPO / billings) 是核心节奏
- **MSFT Copilot 类话题**可在本板块（Copilot 商业化角度）写，AI 模型层面归 AI 板块——不要重复
- 久谦企业 IT 调研对本板块特别有价值（seat 数、续约、定价反应）
